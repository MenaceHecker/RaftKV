# D3: `make release` (reproducible linux/arm64 build, versioned, sha256, separate S3 upload)

Planner: Claude, read-only, based on `origin/main` ea7583f. **Nothing was run or built**; "(unverified)" marks claims I did not check. Branch `feat/d3-release`. Go is `go 1.25.0`, no `toolchain` line (`go.mod:3`).

## Goal
`make release` builds `raftkv-server` and `gateway` for linux/arm64 reproducibly, stamps version/commit/date (shown by `-version`), writes sha256 files and a manifest to `dist/<version>/`, and verifies them. It needs no AWS and
never uploads. `make release-upload` is a different target that pushes a verified `dist/<version>/` to S3 only with an explicit profile and bucket, never in CI. The executor never runs it or any `aws` command.

## Invariants touched
None of §7 (no Raft change). §2: no secrets, no IAM users/keys, no terraform. Release artifacts are immutable per version (never overwritten).

## Files to create or change
- `internal/buildinfo/buildinfo.go`: `var Version, Commit, Date = "dev", "unknown", "unknown"` (set by `-X github.com/MenaceHecker/raftkv/internal/buildinfo.Version=...`), `func Line(prog string) string` returning one line `prog <Version> <Commit> <Date> <GOOS>/<GOARCH> <go version>` (from `runtime`). Never print paths or hostnames.
- `cmd/raftkv-server/main.go`, `cmd/gateway/main.go`: a first-argument `-version` or `--version` prints `buildinfo.Line(...)` to stdout and exits 0 **before any other flag or file is read** (server: in `run()` before `defineFlags`; gateway: in `run()` before `loadSettings`). Only exact first-arg match; no new flag registration, so `-help` output and existing tests are unchanged.
- `scripts/release.sh`: no AWS. Steps: (1) resolve `VERSION=$(git describe --tags --always --abbrev=12)`, `COMMIT=$(git rev-parse HEAD)`, `DATE=` the **commit** date in UTC (`git show -s --format=%cd --date=format:%Y-%m-%dT%H:%M:%SZ`), never `date now`; (2) dirty = tracked changes or untracked `*.go`/`go.mod`/`go.sum` (not other untracked files: the main checkout holds untracked `review-*.md`); dirty **refuses** unless `ALLOW_DIRTY=1`, then `VERSION` gets `-dirty`, `COMMIT` gets `-dirty`, manifest says `dirty=true`; (3) reject a `VERSION` with `/` or whitespace; (4) build each into `dist/<version>/` with `CGO_ENABLED=0 GOOS=linux GOARCH=arm64 GOFLAGS=-mod=readonly GOWORK=off go build -trimpath -buildvcs=false -ldflags "-s -w -buildid= -X ...Version=$VERSION -X ...Commit=$COMMIT -X ...Date=$DATE"` (no tags, so the gateway has no fakecluster); outputs `raftkv-server-linux-arm64`, `gateway-linux-arm64`; (5) write `<file>.sha256` (`<hash>  <file>`, `sha256sum -c` format; use `sha256sum` or `shasum -a 256`); (6) write `MANIFEST` (key=value: version, commit, date, dirty, go version, goos/goarch, then the two sha lines); (7) run `scripts/verify-release.sh dist/<version>`. Overridable `DIST_DIR` (default `dist`) for tests. `dist/` goes into `.gitignore`.
- `scripts/verify-release.sh <dir>`: exits non-zero with a one-line reason per check: both binaries, `.sha256` files and `MANIFEST` present; recomputed sha256 equals the `.sha256` file and the manifest; `go version -m <bin>` shows `GOOS=linux GOARCH=arm64 CGO_ENABLED=0 -trimpath=true` and the three `-X` values equal the manifest (works on stripped binaries, unverified); **fakecluster**: `go list -deps ./cmd/gateway` (no tags) has no `fakecluster`, **and** the gateway binary contains no `internal/gateway/fakecluster` via `strings` (symbols are stripped by `-s`, so `go tool nm` cannot be used; function names stay in pclntab, unverified; if the string check proves unreliable the executor keeps only the `go list` check and says so); no build path (`$PWD`, `$HOME`) in either binary (proves `-trimpath`). It never executes an arm64 binary.
- `scripts/release-upload.sh <dir>`: refuses (exit non-zero, **before any aws call**) when: `CI` or `GITHUB_ACTIONS` is set; `RELEASE_AWS_PROFILE` or `RELEASE_BUCKET` is empty; `AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY`/`AWS_SESSION_TOKEN` is in the environment (no long-lived keys, D0; the profile must be SSO); `MANIFEST` says `dirty=true`; `verify-release.sh` fails; the object already exists (`aws s3api head-object` succeeds). Then `aws --profile "$RELEASE_AWS_PROFILE" --region us-east-1 s3 cp` each file to `s3://$RELEASE_BUCKET/artifacts/raftkvd/<version>/` (node binary + `.sha256`) and `.../artifacts/gateway/<version>/` (gateway + `.sha256`), `MANIFEST` copied to both, **MANIFEST last**. Prints the S3 URIs; no `--acl`, no delete, no `sync --delete`.
- `Makefile`: `release:` -> `scripts/release.sh`; `release-upload:` -> `scripts/release-upload.sh dist/$(VERSION)`... (`VERSION` is computed by `release.sh`; `release-upload` takes `RELEASE_DIR=dist/<version>` explicitly, no default); add both to `.PHONY`. `.gitignore`: `/dist/`.
- Tests: `scripts/release_test.sh`, `scripts/verify-release_test.sh`, `scripts/release-upload_test.sh` (style of `scripts/guard-tests_test.sh`: `mktemp -d`, `ok`/`FAIL` lines, exit 1 on failure), `internal/buildinfo/buildinfo_test.go`, `cmd/raftkv-server/version_test.go`, `cmd/gateway/version_test.go`.

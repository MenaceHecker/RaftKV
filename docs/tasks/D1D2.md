## Port reconciliation (human reads this table; code facts, not the runbook's)
Code: nodes run ONE shared gRPC `--listen` carrying Raft + KVService + ClusterService (`cmd/raftkv-server/main.go:78-79,168,347-362`, `docs/tasks/D5b.md:84`); AdminService on a separate `--admin-listen` (`main.go:95,272-294`, needs token); metrics on `--metrics-listen`, default OFF (`main.go:93`); gateway `--listen` defaults `:8080` plain HTTP, TLS/80/443 is D6 not yet built (`cmd/gateway/main.go:49`, `docs/gateway.md:55`); gateway dials node `--listen` and `--admin-listen` addresses (`docs/gateway.md:16-17`).
| SG rule | §10.4 says | Code says | Card default |
|---|---|---|---|
| sg_nodes in, peers | 7000 from nodes+gateway | Raft shares the client port; no separate 7000/7001 | ONE rule, tcp/7000 (shared `--listen`, per `docs/gateway.md:11`), from sg_nodes and sg_gateway. OPEN Q1 |
| sg_nodes in, client | 7001 from gateway | same listener as above | NO 7001 rule (collapsed into 7000) |
| sg_nodes in, admin | 9000 from gateway | `--admin-listen`, gateway dials it | tcp/9000 from sg_gateway |
| sg_nodes in, metrics | 2112 from gateway | no default; nobody in the gateway code scrapes it (unverified, not found in cmd/gateway) | tcp/2112 from sg_gateway, kept per §10.4. OPEN Q2 |

## Goal
(D4) `infra/compute/`: 3 node instances (fixed `.10` IPs, one per private subnet) and 1 gateway instance (public subnet, Elastic IP), user-data that installs the binary from S3 (sha256-pinned), writes flags into a systemd unit, and never contains a secret. (D6) `cmd/gateway` gains TLS via `autocert`, plain HTTP kept for local use. DNS A record, SSM parameters and `apply` are the human's.

## Invariants touched
None of RUNBOOK §7 is changed; §7.3 (WAL fsync) is preserved by leaving `--fsync` at its default `true` (`cmd/raftkv-server/main.go:88`). Hazard: replacing a node instance wipes its WAL and votedFor, so `user_data`/`ami` changes must never auto-replace a node (see Files).

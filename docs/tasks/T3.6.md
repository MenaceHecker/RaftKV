## Decided: Glob -> ReadDir error behavior (deliberate change, flag it)
`sweepTemporaries` uses `filepath.Glob` (`snapshot.go:53`), which silently ignores directory-read errors. `ReadDir` returns them.
Decision: **surface the error**: `NewSnapshotter` fails with `storage: scanning for partial snapshots: ...`. Keep the suffix filter
(`*.snap.tmp`) and do **not** add an `IsDir` check, so a matching directory is still removed as Glob+Remove did. State this exception
in the commit message, the PR description and the report; everything else stays behavior-preserving.
